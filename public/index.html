1

프로젝트 관리

스크립트를 프로젝트 단위로 묶고, 프로젝트마다 사용자와 키를 따로 관리합니다.

2

로더 한 번에 복사

3

API 키 / 스크립트 키 분리

API 키는 관리자 계정 접근용이고, 스크립트 키는 사용자가 로더에 넣는 키입니다. 메뉴도 따로 나뉩니다.
